# Mi primer repositorio Git 🚀

Este repositorio forma parte de mi proceso de aprendizaje en *Linux, Git y Cloud Computing*.  
El objetivo es practicar control de versiones y buenas prácticas usando Git y GitHub.

---

## 📌 Contenido del repositorio

- index.html → archivo de prueba para practicar commits
- texto.txt → archivo de ejemplo
- Scripts y archivos creados durante el aprendizaje

---

## 🛠️ Tecnologías utilizadas

- Git
- GitHub
- Terminal (Git Bash)
- Linux (Ubuntu / VirtualBox)

---

## 📚 Qué aprendí en este proyecto

- Inicializar un repositorio Git
- Agregar archivos al staging (git add)
- Crear commits (git commit)
- Manejar ramas (main)
- Conectar repositorio local con GitHub
- Subir cambios con git push
- Autenticación con *Personal Access Token*
